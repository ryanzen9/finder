## Design Context

### Users
Individual users who want to organize and manage product manuals. Users photograph product documentation, upload images, and search/retrieve manuals when needed. The app serves as a personal digital filing cabinet for product information.

### Brand Personality
Modern & sleek - sophisticated, clean, and functional. The interface should feel professional yet approachable, with subtle sophistication rather than flashiness.

### Aesthetic Direction
- **Visual tone**: Modern, clean, Material 3 design
- **Color**: Teal-based seed color (light: 0xFF006A6A, dark: 0xFF80D5D5) generated via ColorScheme.fromSeed()
- **Theme**: Supports both light and dark modes with user preference
- **Typography**: Material 3 defaults, readable and clear
- **Spacing**: Generous but purposeful padding (12-16px standard padding)
- **Components**: Rounded corners (14-24px radius), cards with subtle elevation, modal bottom sheets

### Design Principles

1. **Utility first** - Every design decision should serve the user's goal of finding manuals quickly. Avoid decorative elements that don't add value.

2. **Clean sophistication** - Use Material 3's built-in elegance. Rely on whitespace, typography, and subtle shadows rather than bold colors or heavy decorations.

3. **Consistent patterns** - Follow existing patterns in the codebase:
   - Use Cards with Clip.antiAlias for content containers
   - Rounded search bars (24px radius)
   - Modal bottom sheets for detail views
   - Grid layouts for library views (2 columns, 12px spacing)

4. **Respect user preference** - Maintain both light and dark themes with equal attention. The theme is already implemented via ThemeMode.system in main.dart.

5. **Approachable for all** - Ensure good contrast ratios, readable text sizes, and clear touch targets. The app should feel welcoming regardless of user's technical comfort level.

### Established UI Patterns

**Cards & Containers:**
- Cards: `elevation: 0`, use `clipBehavior: Clip.antiAlias`
- Border radius: 14-20px for cards, 24px for search bars

**Grid Layouts:**
- 2 columns with 12px spacing (both mainAxis and crossAxis)
- childAspectRatio: 0.72-0.9 for manual cards

**Buttons:**
- FAB: Use `FloatingActionButton.extended` with rounded shape (`BorderRadius.circular(16)`)
- Use FilledButton, OutlinedButton from Material 3

**SnackBars:**
- Always use `behavior: SnackBarBehavior.floating`
- Use theme colors: `colorScheme.primary` for success, `colorScheme.error` for errors

**Bottom Navigation:**
- Use Material 3 `NavigationBar` with `NavigationDestination`

**Modals:**
- Use `showModalBottomSheet` with `showDragHandle: true`, `isScrollControlled: true`, `useSafeArea: true`
- Typical heightFactor: 0.72-0.78 for detail sheets
